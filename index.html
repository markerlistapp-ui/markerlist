// redundancy

Your backup is already running.

PRO MULTI ONLY

For critical shows, Pro Multi keeps a second computer running in parallel with your main Ableton system. If the main computer fails, take over in one tap and keep the show moving.

LIVE MIRRORING

Two computers. One show.

Every relevant change on the main computer is mirrored to the backup in real time — setlist order, chained sections, loop cues, mixer levels, mute/solo and track routing.

ONE-TAP TAKEOVER

Switch without rebuilding.

If the main Ableton session stops responding, the backup surfaces a clear alert. Confirm the takeover and the backup becomes the new host — no re-cabling, no re-pairing devices, no lost setlist.

SILENT STANDBY

Ready when you need it.

The backup machine stays muted while on standby, so it cannot send audio to the house mix. The switch is deliberate and remains under your control.

// faq

Before you take it on stage.

Does Markerlist modify my Ableton project?

No. Markerlist controls your session without modifying the original Ableton project.

Does it work with Ableton Arrangement View?

Yes. Arrangement View is the core workflow: your existing set stays at the center of the system.

What devices can I use?

Markerlist is cross-platform for control devices: use phones, tablets or computers running Windows, macOS, iOS or Android through a browser. Each opened browser window counts as one device. Currently, only the host computer running the Ableton session must be a Mac.

Does Markerlist add CPU load to Ableton Live?

No. Markerlist is not an Ableton plugin and does not run inside your Ableton project. It operates externally, so it does not add plugin processing or CPU load to the session.

Can multiple people control the same set?

Yes. Multi plans let you connect multiple devices and assign roles and permissions.

What happens if the Wi-Fi connection drops?

Markerlist automatically reconnects and restores the current state so a temporary network drop does not leave you with stale controls.

What is Pro Multi?

Pro Multi adds two-machine redundancy: a second computer runs in parallel and can take over if the main computer fails. Only one Pro Multi licence is required for the two computers. The licence is shared between them during the pairing process, so you do not need to purchase a second licence for the backup computer.

Can I try Markerlist before buying?

Yes. Discovery lets you test Markerlist in your real setup before choosing a paid plan.
