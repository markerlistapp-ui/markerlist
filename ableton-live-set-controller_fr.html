Contrôleur de set Ableton Live — FAQ

Qu’est-ce qu’un contrôleur de set Ableton Live ?

C’est une interface permettant de piloter un set Ableton Live pendant un spectacle sans rester devant l’ordinateur principal. Markerlist est spécifiquement conçu pour les sets live construits dans la vue Arrangement.

Puis-je contrôler mon set depuis un iPad ou un téléphone ?

Oui. L’interface Markerlist fonctionne dans un navigateur, donc un iPad, un téléphone ou un ordinateur peut servir d’appareil de contrôle sur le réseau local.

Markerlist remplace-t-il Ableton Live ?

Non. Ableton Live reste l’environnement hôte et de lecture. Markerlist fournit une interface externe de contrôle du set.

Markerlist modifie-t-il mon projet Ableton ?

Non. Markerlist fonctionne en externe et n’écrit pas de modifications dans le projet original.

Ai-je besoin d’un plugin ou de Max for Live ?

Non. Markerlist n’est pas un device Max for Live et ne nécessite pas de plugin Markerlist dans le projet.

Combien d’appareils puis-je utiliser ?

Le nombre dépend du forfait. Un appareil correspond à une fenêtre de navigateur ouverte.
