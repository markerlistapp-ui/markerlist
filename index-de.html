// reliability

When the show can't stop.

Pro Multi adds a second Mac running a mirrored Ableton show, ready to take over when the main computer has a problem.

Live mirroring

The backup machine mirrors the show state, including setlist order, sections, loop cues and track controls.

One-tap takeover

If the main computer fails, the backup can become the active host without rebuilding the show or reconnecting the control devices.

Silent backup

The backup remains muted while on standby. Switching over is deliberate, so the backup does not unexpectedly reach the house mix.

LTC backup

Pro Multi also includes the LTC backup workflow for keeping the backup system synchronized when the primary Ableton machine is unavailable.

// frequently asked questions

Bevor du startest.

Does Markerlist modify my Ableton project?

No. Markerlist controls your session externally and does not write changes into your original .als project.

Do I need Max for Live or a plugin?

No. Markerlist does not require Max for Live or a Markerlist plugin to be loaded into your Ableton project.

Does Markerlist work with Arrangement View?

Yes. Arrangement View is the core workflow: build your show in Ableton, then use Markerlist as the live control layer.

What devices can I use?

The control interface runs in a browser on iOS, Android, Windows or macOS. The computer hosting the Ableton session is currently a Mac.

Can I control Ableton tracks?

Yes. Markerlist provides essential track controls such as mute and solo, plus track-level controls available in the app. It is intended as a stage-side control and safety tool, not as a replacement for Ableton's visual mixer.

Can multiple people connect to the same show?

Yes. Multi plans allow several control devices to connect to the same show, with roles and permissions available on supported plans.

Can I use a backup computer?

Yes. Pro Multi adds two-machine redundancy, with a second Mac running a mirrored show and ready to take over when needed. LTC backup is also included.

Can I try Markerlist before buying?

Yes. Discovery is free and lets you test Markerlist with your own setup before choosing a paid plan.
